# Hello

A simple "Hello, World!" program written in Go.

## Getting Started

### Prerequisites

- Go 1.25.4 or later

### Building

```bash
make build
```

This will compile the program and create a `hello` binary.

### Running

```bash
make run
```

This will compile and run the program directly.

Or run the compiled binary:

```bash
./hello
```

### Cleaning

```bash
make clean
```

This will remove the compiled binary.

## Project Structure

- `hello.go` - Main Go source file
- `go.mod` - Go module definition
- `Makefile` - Build automation
- `README.md` - This file
